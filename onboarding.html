My Azure Portal Extension setup

Enhance your Azure Portal experience

My Azure Portal Extension adds practical customization, privacy, and administration features directly in your browser while you use the Azure Portal.

Works immediately — no sign-in needed

These features are available right away from the extension's settings popup. No setup is required.

  • Custom background image for the Azure Portal, including URL and opacity settings
  • Mask your account name in the portal header
  • Mask your Microsoft Entra tenant name
  • Mask subscription IDs and other GUID-formatted values shown in the portal

Requires signing in (extra setup)

These features call the Azure Resource Manager API on your behalf:

  • Highlight empty resource groups
  • Direct user RBAC panel, showing your own role assignments per subscription and resource group

To use them, sign in with your own Microsoft Entra ID account and complete a one-time setup by registering a small Entra ID App that you own, using its Tenant ID and Client ID. This is optional: if you only want the features in the section above, you can skip it entirely. See Register an Entra ID app and Quick start (v0.4.0) in the README.

  • Usage telemetry is optional and OFF by default.
  • Only anonymous aggregated feature counts are sent.
  • No user identifier, tenant name, URL, or resource name is sent.
